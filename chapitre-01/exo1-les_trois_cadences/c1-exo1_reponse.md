 Exercice 1 — Les trois cadences

La durée d'une image se calcule avec la formule :

Durée d'une image = 1000 / fréquence

 72 Hz

1000 / 72 = 13,9 ms

Temps restant pour le code :

13,9 - 8 = 5,9 ms

 90 Hz

1000 / 90 = 11,1 ms

Temps restant pour le code :

11,1 - 8 = 3,1 ms

 120 Hz

1000 / 120 = 8,3 ms

Temps restant pour le code :

8,3 - 8 = 0,3 ms

 Réponses finales

- 72 Hz : 5,9 ms
- 90 Hz : 3,1 ms
- 120 Hz : 0,3 ms
